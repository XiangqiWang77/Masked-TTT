# 同一训练状态的 KV 写入精度对照

在固定的 GPT-OSS 开发快照中，使用原始 Value 学习率时，选中 Value 修正写入 BF16 后的平方误差中位数约为预期修正能量的 62.9%；同题将学习率提高到 0.0003 或 0.001 时，这个比例分别约为 22.4% 和 2.6%。这表明小修正会受到缓存精度影响；它不直接说明舍入是回答错误的原因，也不表示增大学习率一定更好。

本对照使用一次原方法训练：Decision API 缓存选块、独立选中 Teacher、全文 Student 的 on-policy KL，只更新选中位置的读取状态。随后将**同一个训练状态**分别物化到 BF16 Value 与 FP32 Value 的独立选中 KV 中，比较正式答案；不引入第二个训练目标或参考答案。也分别测量同后端的零更新和训练后结果。

FP32 Value 当前使用 eager attention，BF16 使用普通后端，所以两种结果的直接差异同时包含数值后端差异；FP32 零更新对照用于区分这种变化与训练效果。成对诊断运行 FP32 时会临时保留 BF16 Cartridge，报告中的单个 Cartridge 大小不代表成对实验的显存峰值。正式路径不保留全文 KV、选中源 KV、优化器或训练状态。

开发样本与长轨迹步数试验相同：每模型 56 题，来自 14 个来源问题，包含 20 道 QA3；样本按题型和来源编号选定，不使用答案标签。结果采用统一宽松词面评分，仅在生成后读取参考答案。FP32 会占用更多选中缓存和计算，实际质量与空间变化由实验测量。
