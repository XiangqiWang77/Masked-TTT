# 受控测试：未选中的全文信息能否影响独立 Cartridge？

这个测试针对一个具体问题：最终回答时全文 KV 已经释放，全文训练得到的读取状态是否能把一条未选中的连接事实带入 Cartridge？

## 对照怎么构造

构造两篇只差一条句子的文档：

- 文档 A：Daniel 拿起牛奶，**去了花园**，然后放下牛奶。
- 文档 B：Daniel 拿起牛奶，**去了办公室**，然后放下牛奶。

两篇文档使用相同的问题“牛奶在哪里？”，并人为固定相同的两个选中片段：“拿起牛奶”和“放下牛奶”。改变的地点句在未选中的中间块。实验先确认两次 Teacher 的选中内容和问题 token 完全一致，零更新的选中缓存也产生相同结果。这里人为固定选块是为了隔离变量，BABILONG 主实验仍使用 Decision API 分数。

两次分别按原有方法在全文 Student 上做 Teacher→Student 的 on-policy SD，仅更新选中 KV 的请求内读取状态。随后将各自状态物化到同一内容的独立选中 KV，并释放全文缓存、选中源缓存和训练参数。训练完成后，才从**物化后的独立卡带**计算“garden”和“office”的候选词概率；候选答案不进入训练目标或最终回答提示。卡带的自由生成与动态读取及重复读取也逐项核对。

## 看什么结果

令 $m_D=\log p(\text{garden}\mid E,Q,\phi_D)-\log p(\text{office}\mid E,Q,\phi_D)$。我们比较 $m_{D_A}-m_{D_B}$：

- 如果它为正，卡带对两种地点的相对支持朝着与全文改变一致的方向发生了变化。
- 同时检查全文原模型是否能区分两种情况、卡带的自由生成是否能区分两种情况，以及 $g$、Value 系数和固定低秩基是否发生变化。
- 两次零更新的选中视图必须相同；否则无法把差异归因于全文条件下的训练。

读取状态变化或候选词概率变化不是最终答对的充分条件；单个合成对照也不能证明平均准确率改善。若全文模型本身没能区分两种情况，该对照对“转移全文中已有的正确关系”的说明力会更弱。
