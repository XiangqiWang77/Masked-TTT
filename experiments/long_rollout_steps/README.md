# 强化 SD 信号后的更新步数对照

在已有 Qwen QA3 的严格配对中，学生前缀从 8 token 延长后，19 道题的地点词进入训练轨迹，首步 KL 和读取状态梯度明显变大；但同题的全文答案和最终独立 Cartridge 答案没有改变。这是一个具体的优化瓶颈，不能据此推断所有题型都会如此。

本实验沿用 OLMo 风格的选中 ICL Teacher、全文 Student、on-policy KL、按选中位置更新的 KV 读取状态，以及独立选中 KV 物化。它从已缓存的 Decision API 分数构造约 10% 的关联选块，学生轨迹上限为 32 token；在同一条优化轨迹中保留 2、4、8 个基础更新步的状态。每个已核验练习额外计一个更新，与原方法一致；没有在选中缓存上训练，也没有额外全文到选中缓存的损失。

每模型预先固定 56 题：QA3 的全部 5 个开发来源问题，再加其他 9 种题型各 1 个来源问题，每题分别评测 8K、16K、32K、64K。来源仅按题型和编号确定，不使用答案标签。这个有意侧重 QA3 的开发样本不是完整 BABILONG，也不是独立 56 道来源问题。

2/4/8 步检查点使用同一 Teacher、同一证据缓存、同一原问题和同一生成预算。2/4 步是从保存的训练状态做的配对诊断；8 步最终输出来自释放全文 KV、选中源 KV 和训练状态后的独立物化 Cartridge。中间快照临时转移到 CPU，正式解码前释放。统一宽松词面评测只在生成后使用参考答案。结果必须先验证，不能根据较强梯度或更多步数预先认定准确率提升。
