# 统一宽松判分复核：Qwen 与 GPT-OSS 各 1,000 题

这次复核读取两个已完成的 BABILONG 1,000 题运行，对每题的全文、选中缓存零更新、ICL Teacher 和训练后 Cartridge 重新执行同一个 `answer_focused_lexical_v2` 评分器。**8,000 个答案的重算分数与已保存的报告全部一致**。它没有重新生成答案、改变已有分数或调用模型/API；参考答案仅在生成后用于评分。每个模型的 1,000 题来自 250 个来源问题在四种长度下的版本。

| 模型 | 方法 | 答对 | 未能解析 | 位置/实体题中答对但末尾仍含多个候选标签 |
|---|---|---:|---:|---:|
| Qwen3-4B | 全文 | 544 | 0 | 3 |
| Qwen3-4B | 选中零更新 | 560 | 0 | 0 |
| Qwen3-4B | ICL Teacher | 566 | 2 | 0 |
| Qwen3-4B | Cartridge | 567 | 1 | 0 |
| GPT-OSS-20B | 全文 | 487 | 0 | 1 |
| GPT-OSS-20B | 选中零更新 | 551 | 0 | 0 |
| GPT-OSS-20B | ICL Teacher | 571 | 0 | 0 |
| GPT-OSS-20B | Cartridge | 554 | 0 | 0 |

两模型在 yes/no/maybe 题上的四个方法均没有出现未解析输出。对物品集合题，脚本还筛查了「被判错，但回答明确列出的物品集合与标准集合一致、没有否定或不确定词」这一类可能漏判；上述八组中筛出数均为 0。

这是一项针对已知格式问题的自动筛查，**不是 LLM 语义复核**，不能证明每一题的含义判断都正确。表中的多标签数是需要复核的线索，不直接等于误判数；其他表达方式也可能遗漏。新的实验继续统一使用这套规则，若以后采用语义判分，应对所有方法的同一批输出一起重判。
