# 首步 Teacher KL 与卡带回答变化

读取已完成的每模型 1,000 道 BABILONG 日志；每 1,000 题由 250 个来源问题扩为四种长度。0.01 是描述性分组阈值，不是训练门控；每题训练仍使用原有全文 Student 和选中 Teacher 的 KL。

| 模型 | 首步 KL | 题数 | 原格式 token 序列变化 | 原格式新对 / 新错 | 同 Teacher 格式新对 / 新错 |
|---|---:|---:|---:|---:|---:|
| qwen | < 0.01 | 357 | 1 | 0 / 0 | 0 / 1 |
| qwen | ≥ 0.01 | 643 | 56 | 15 / 8 | 10 / 7 |
| gpt | < 0.01 | 271 | 5 | 2 / 0 | 0 / 1 |
| gpt | ≥ 0.01 | 729 | 20 | 6 / 5 | 10 / 5 |

每列的新对与新错都比较同一选中缓存、相同问题格式和生成长度的零更新与训练后答案。首步 KL 衡量选中 Teacher 与全文 Student 在其前缀上的分布差异，不是正确性分数。不同题型和提示会影响 KL；该分组用于定位训练信号，不能直接确定最佳更新参数。

Qwen 的低 KL 组几乎没有生成变化，说明值得检验更长的学生前缀是否让答案位置获得训练信号；当前更长前缀和提示对齐的配对实验负责验证最终准确率。

[聚合数据](summary.json)不包含原文、答案或逐题身份。没有新模型或在线 API 调用。
