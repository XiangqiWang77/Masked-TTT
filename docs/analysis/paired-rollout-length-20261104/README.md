每个模型各 200 题开发集；表内仅保留选块、Teacher 生成 token、零更新 token、自练习及学生前 8 个 token 一致的题。训练目标均为全文 Student 对独立选中 Teacher 的 on-policy KL，表中比较相同两步预算的选中缓存输出。

两侧的两步输出都是释放选中源缓存前的配对诊断，两轮可能使用不同 GPU，也未保存 Teacher 的完整概率张量；因此匹配的是可见运行条件，不能称为同一次运行。更长前缀的首步 KL 均值涵盖更多位置，不能把大小直接解释成同位置改善。

QA3 组的梯度增加而答案不变，说明这批 QA3 题里仅延长训练前缀未带来可观察的答案变化；它不能单独确定变化损失在全文到卡带的哪一环。完整数据均已完成，本审计未重新调用模型或 API；二值准确率来自先前生成后的统一宽松词面评分。
