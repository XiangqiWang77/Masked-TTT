# 物化后移除重复读取参数：存储估算

训练完成后，注意力偏置和 Value 修正已经写入选中 KV。下面从已保存的逐题字节统计中，比较“物化 KV 加读取参数副本”和“仅物化 KV”两种卡带本体。每题先计算卡带与全文文档 KV 的比例，再取中位数。

| 模型与固定快照 | 题数 | 原卡带 / 全文 KV | 仅物化 KV / 全文 KV | 每题估算节省中位数 |
|---|---:|---:|---:|---:|
| Qwen3-4B，完整运行 | 1,000 | 14.43% | **14.06%** | 10.20 MiB |
| GPT-OSS-20B，历史快照 | 563 | 20.81% | **20.06%** | 4.97 MiB |

这些数字根据原运行中记录的物化 KV 和参数字节数计算，属于对新路径的估算。它们不包括模型权重、问题与答案后缀、优化器或训练阶段峰值显存。两种真实模型均已在短 GPU 样本上验证，删除副本前后生成结果和 logits 保持一致；完整题集的新路径仍需实际运行。
