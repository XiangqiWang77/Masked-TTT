# Decision 选块在两种模型分词下的原文覆盖

Decision 分数对应原文字符区间，而 Qwen3-4B 和 GPT-OSS-20B 使用不同分词器。这个检查复用已完成的 200 题开发集选块，在每个模型的完整原始提示中重新取得 token 字符位置，再比较**选中原文区间**与实际被选中的模型 token 所覆盖的非空白字符。200 题来自 50 个来源问题的四种长度。

| 模型 | 题数 | 选中块总数 | 选中原文遗漏非空白字符的题数 | 选中 token 多覆盖相邻非空白字符的题数 |
|---|---:|---:|---:|---:|
| Qwen3-4B | 200 | 2,449 | **0** | 4 |
| GPT-OSS-20B | 200 | 2,449 | **0** | 4 |

两种模型各自选中区间合计 1,987,091 个非空白字符，检查中均被各自的选中 token 覆盖。四个多覆盖的题在每种模型上合计各多覆盖 4 个相邻非空白字符，这是 token 横跨源区间边界时的现象。

这排除了这批题上“已选中的原文片段被模型分词遗漏非空白字符”这一具体问题。它不衡量 Decision 是否选中了必要证据，也不证明模型读取或理解了这些字符；另一个[支持事实分组](../linked-value-reproduction-20261104/README.md)使用生成后标注单独检查证据覆盖。本检查不读取参考答案、不加载模型权重、不调用模型或 API，也没有重新生成答案。
