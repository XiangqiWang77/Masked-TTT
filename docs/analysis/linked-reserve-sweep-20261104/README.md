# 同一 10% 预算下，关联选块能补全多少证据？

这项事后分析使用固定的 BABILONG 200 题开发集：50 个源问题，每题四种长度。选块只使用文档、问题和已有 Decision API 分数；在选块完成后，才用任务的支持事实标注检查覆盖。关联名额比例指**已选块名额**中用于实体关联补充的比例，不是整篇文档的比例。全部配置保持相同的每题选块数量，汇总后为 2,449 / 23,474 块（10.43%）。

| 关联名额比例 | 全部标注支持事实被选中 | 相对纯分数选块：新完整 / 失去完整 |
|---|---:|---:|
| 0%：纯 Decision 分数 | 125 / 200 | — |
| 12.5% | 153 / 200 | 31 / 3 |
| 25% | 157 / 200 | 36 / 4 |
| 50% | 158 / 200 | 37 / 4 |

两个已经有模型答案的配置也做了同题比较：Qwen3-4B 的 Cartridge 从纯分数选块的 53.00% 变为 25% 关联名额的 58.50%，该关联选块的 ICL Teacher 为 59.50%。逐题变化和覆盖分组见[配对报告](../linked-coverage-qwen-20261104/README.md)。12.5% 和 50% 只有本次覆盖分析，没有对应的新模型回答，不能由覆盖数推出其准确率或选择最优训练配置。

标注覆盖衡量的是选中原文是否包含支持事实，不证明模型使用了它们。四种长度共享源问题；最终效果要以留出的源问题上、同一评分规则下的回答质量判断。本次只使用本地数据与缓存分数，没有调用模型或在线 API。选择结果为每题固定数量，且 0% 和 25% 的选择与覆盖分别逐题核对了此前的完整 200 题记录。
