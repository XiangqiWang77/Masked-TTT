同题配对显示，关联选块方法相对原选块 Cartridge **新答对 34 题、新答错 23 题**，净增 2.63 点。固定关联选块与原问题格式后，训练前后新答对 7 题、新答错 1 题，净增 1.43 点。固定关联选块和 Teacher 格式后，零更新为 61.10%、训练后为 61.81%，新答对 6 题、新答错 3 题，净增 0.72 点。

在这 419 题中，全文答对而 Teacher 答错的有 44 题，卡带答对其中 1 题；Teacher 答对而全文答错的有 69 题，卡带答对其中 64 题。这给出下一步的明确目标：保留聚焦 Teacher 的优势，同时让更多全文独有的正确信息进入独立卡带。两种阅读条件使用各自的实际输出格式。

全文和 Teacher 都错的 119 题中，卡带答对 7 题；其中 1 题是同格式零更新答错、训练后答对，其余 6 题的零更新卡带已答对。

ICL Teacher 使用通用输出要求及 32-token 上限；卡带的两个格式对照分别使用原问题或相同的通用输出要求，且零更新与训练后共享生成预算。因此同格式的零更新对照更适合观察训练变化。原选块与关联选块可能在不同 GPU 上运行，405 / 419 题的全文输出完全一致。

该 800 题集合按源问题与开发集分开，配置在生成前固定；其中两个源问题此前曾被定性查看，当前快照包含其中 3 题，另有 416 题不含这两个源问题。此前也查看过整批数据的聚合结果，所以不将其称为完全盲测。各题型、长度及排除上述来源后的统计见[聚合数据](summary.json)。
