# OLMo 涨点的跨模型复现记录

目标是在 Qwen3-4B 和 GPT-OSS-20B 上复现 OLMo 的 Query Cartridge 提升。各组都复用 Decision API 缓存分数，以选中原文构造 Teacher、全文作为 Student，通过 on-policy KL 更新选中位置的读取参数，再将更新物化到独立的选中 KV，使用原问题生成。评分统一为 `answer_focused_lexical_v2` 宽松词面评分；预测和训练不读取评测答案。

## 相同原始选块设置

每个模型的 1,000 题来自相同的 250 个来源问题，各有四种上下文长度。

| 模型 | 题数 | ICL Teacher | Cartridge | 相对 Teacher |
|---|---:|---:|---:|---:|
| OLMo-3-7B | 1,000 | 41.20% | **44.60%** | **+3.40 点** |
| Qwen3-4B | 1,000 | 56.60% | **56.70%** | **+0.10 点** |
| GPT-OSS-20B | 1,000 | 57.10% | 55.40% | −1.70 点 |

这是原实验各自 Teacher 与 Cartridge 的完整方法对比。Teacher 使用额外的通用回答格式要求，Cartridge 使用原问题格式；因此该差值同时包含输出格式和训练等因素。[逐模型汇总及题型分组](../olmo-reproduction-signal-20261104/README.md)。

## 当前改进配置

| 模型与设置 | 题数 | 同缓存零更新 | ICL Teacher | Cartridge | 相对零更新 | 相对 Teacher |
|---|---:|---:|---:|---:|---:|---:|
| Qwen，关联选块 | 1,000 | 59.40% | 61.30% | **60.20%** | **+0.80 点** | −1.10 点 |
| GPT-OSS，关联选块 + 更强 Value 学习率 | 200 开发题 | 61.00% | 62.00% | **62.50%** | **+1.50 点** | **+0.50 点** |

两行中的零更新与 Cartridge 使用同一选中缓存、原问题格式和生成预算；Teacher 使用额外的通用回答要求。Qwen 的完整 1,000 题见[关联选块报告](../linked-value-reproduction-20261104/README.md)，GPT-OSS 的 200 题及与原设置的配对见[组合配置报告](../linked-value-reproduction-20261104/README.md)。200 题由 50 个来源问题扩展而来，已用于选择配置；GPT-OSS 另外 800 题的留出评测正在运行。

作为参数更新的单独对照，OLMo 另一次同缓存、同格式配对复跑是 **44.30% → 44.50%**。这说明方法级的 +3.40 点不能全部归给 SD 更新。[完整说明](../olmo-reproduction-signal-20261104/README.md)。

## 正在验证

- **GPT-OSS：** 固定开发集中优于同轮全文、零更新和 Teacher 的关联选块及 Value 学习率组合，继续评测 800 题。
- **Qwen：** 在同一模型和 GPU 上配对检验更长 Student 前缀与 Value 学习率的组合；另有选中原文重新分词的配对评测。证据来源、全文 Student、自蒸馏目标和卡带物化均保持原方法。
- **两模型：** 已提交单 GPU 作业 **32015783**，在同一设备、同一选块和 Teacher 下比较注意力增益学习率 `0.01` 与 `0.03`。每模型 200 道开发题；只有超过该模型同轮全文、零更新、Teacher 和原学习率时，才进入 800 题留出集。[实验协议](../../../experiments/gain_rate_pair/README.md)。
- 候选先与自己的同轮全文、选中零更新和 Teacher 比较；Qwen 新实验还在同一 GPU 上配对原卡带。满足各自预定条件后才扩展至来源问题不重叠的留出题。报告同时列出新答对和新答错，不把开发集准确率当作全量结果。

公开实现的可选证据分词入口及测试见[说明](../evidence-tokenization-20261104/README.md)。这一入口默认关闭；现有结果无需重新调用 Decision API。
