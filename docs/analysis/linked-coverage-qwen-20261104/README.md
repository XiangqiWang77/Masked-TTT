# 关联选块的收益来自哪里？

对已经完成的 Qwen3-4B 开发集做逐题事后分析。两种策略使用相同的约 10% 块预算：一种仅按 Decision 分数选择，另一种用部分名额补充与高分块相关的实体上下文。参考答案与支持事实标注都只用于生成之后的评分和分组。

| 标注支持事实覆盖变化 | 题数 | 原选块 Cartridge | 关联选块零更新 | 关联选块 Teacher | 关联选块 Cartridge | 新答对 / 新答错 |
|---|---:|---:|---:|---:|---:|---:|
| 总体 | 200 | 53.00% | 57.50% | 59.50% | **58.50%** | 22 / 11 |
| 从不完整变为完整 | 36 | 19.44% | 61.11% | 63.89% | **58.33%** | 16 / 2 |
| 两种选块都完整 | 121 | 69.42% | 64.46% | 66.94% | 66.94% | 2 / 5 |
| 两种选块都不完整 | 39 | 30.77% | 33.33% | 33.33% | 33.33% | 3 / 2 |
| 从完整变为不完整 | 4 | 75.00% | 50.00% | 50.00% | 50.00% | 1 / 2 |

总体净增 11 题；补全标注证据的 36 题净增 14 题，其余组净减 3 题。这支持将关联选块作为后续测试的重点。表格同时显示，补全证据组的关联选块零更新和 Teacher 分别为 61.11% 和 63.89%；不能把从原选块到关联选块的全部收益归因于 SD 更新。

这 200 题对应 50 个源问题的四种长度，属于开发分析。覆盖标注表示选中范围包含事实，并不单独证明模型使用了这些事实；后续仍需在来源问题不重叠的题上测试。
