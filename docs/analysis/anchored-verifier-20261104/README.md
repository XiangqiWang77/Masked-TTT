# 选中原文自学习：短答案核验候选

原 OLMo 风格配置会生成与问题相关的小练习，并用选中原文中的引用独立核验。当前核验要求候选答案和独立复答完全相同：如果候选答案是 “John journeyed to the garden”，独立复答是 “The garden”，这个本来可能有用的练习会被拒绝。

候选规则保留所有原有的精确匹配；额外允许一种情况：候选答案逐字存在于选中引用中，独立复答是该候选答案里唯一出现的短片段。时间先后不明确、答案是 “there” 等指代、否定或多数字歧义的新增匹配不放行。自学习答案不加入 Teacher 或 Student 提示；训练仍在全文 KV 上以选中 Teacher 为目标，只更新请求内读取状态。

对固定的历史输出做离线重放：

| 模型 | 快照题数 | 原核验通过的小题 | 额外通过候选规则的小题 | 涉及题数 |
|---|---:|---:|---:|---:|
| Qwen3-4B | 221 | 50 | 30 | 25 |
| GPT-OSS-20B | 264 | 137 | 7 | 6 |

这些数字只说明核验决策的变化，不是回答准确率。小题还需通过原有的缓存前缀检查，训练效果需要同题实验。规则不读取评测答案，也不调用新 API。

[summary.json](summary.json) 保存聚合结果；[audit.py](audit.py) 使用已保存的生成问题、引用及独立核验回答重放规则。[实现](../../../experiments/anchored_short_verifier/verifier.py)与 [测试](../../../tests/test_anchored_short_verifier.py)位于仓库中。
