# Qwen 与 GPT-OSS 的独立卡带存储

这份结果来自已完成的问题格式对齐开发实验：每个模型 200 题、50 个来源问题分别扩展到 8K、16K、32K、64K，均在 NVIDIA B200 上运行。两种模型都使用约 10% 的关联选块、全文 Student、选中 Teacher、on-policy SD 和独立卡带。此设置的准确率见[对应结果](../aligned-prompt-development-20261104/README.md)。

| 模型 | 题数 | 全文文档 KV | 选中文档原始 KV | 物化卡带 KV | 卡带 / 全文 | 文档 KV 减少 |
|---|---:|---:|---:|---:|---:|---:|
| Qwen3-4B | 200 | 2.95 GiB | 0.34 GiB | 0.42 GiB | **14.12%** | **85.88%** |
| GPT-OSS-20B | 200 | 0.50 GiB | 0.07 GiB | 0.10 GiB | **20.81%** | **79.19%** |

字节数为逐题中位数；比例先逐题计算再取中位数。卡带是释放全文 KV、选中源 KV 和训练状态后的独立文档缓存，包含物化偏置需要的额外维度；问题与生成后缀不计入此表。因注意力结构、缓存维度和固定开销不同，选中约 10% 的文本不等于字节数必然恰好为 10%。

这不代表总显存按相同百分比减少。Qwen 和 GPT-OSS 的模型常驻显存中位数分别为 7.55、39.02 GiB；卡带解码前已分配显存中位数分别为 7.98、39.12 GiB。请求内训练峰值分别为 15.69、40.50 GiB，包含模型和训练状态；它不等于仅解码卡带时的显存。按上下文长度分组的数据保存在[聚合结果](summary.json)，由[审计脚本](../../../experiments/prompt_alignment/physical_memory_audit.py)从完成的运行提取。
