# 原选块下，单独调学习率或步数有多大空间？

这份分析复用已完成的 BABILONG 200 题开发集（50 个源问题，各四种长度），保持原 Decision 分数前约 10% 的选块、全文基底和 OLMo 式 SD。它比较两个已运行的候选族：Value 学习率 `0.0001 / 0.0003 / 0.001`，以及同一训练轨迹的基础更新 `2 / 4 / 8` 步。通过核验的自练习会在基础预算外增加更新。

“逐题最优上界”使用**评测答案事后**在已生成的三个候选中挑答对的那个，因而是一个不能在请求时直接使用的上界，不是新方法的准确率。

| 模型 | 候选族 | 三个候选准确率 | Teacher | 逐题最优上界 | 上界相对 Teacher |
|---|---|---|---:|---:|---:|
| Qwen3-4B | Value 学习率 | 52.50 / 52.50 / 51.50% | 52.50% | 54.00% | +1.50 点 |
| Qwen3-4B | 更新步数 | 52.50 / 53.00 / 51.50% | 52.50% | 53.50% | +1.00 点 |
| GPT-OSS-20B | Value 学习率 | 52.50 / 53.50 / 54.00% | 53.50% | 54.50% | +1.00 点 |
| GPT-OSS-20B | 更新步数 | 52.00 / 51.50 / 54.00% | 53.50% | 54.00% | +0.50 点 |

例如，Qwen 的三个学习率只有 8 / 200 题出现正确与错误的变化；即使事后每题都选最有利的候选，上界仍低于同题全文的 58.00%。这说明要在这批题上追求更大的收益，需要产生不同的候选答案，而不是只在这三个现有结果之间挑选。

这个结论只适用于表中**已生成的候选**和原分数选块；它不限制其他学习率、训练过程或关联选块。正在运行的关联选块＋长前缀＋多步训练属于新的组合，会用其自己的同题对照和留出集判断。Teacher 使用额外通用输出要求，卡带使用原问题格式；同缓存同格式对照另见[配对分析](../linked-contributions-20261104/README.md)。

[聚合数据](summary.json)包含题型和长度拆分，不包含题目、答案或逐题 ID。[分析脚本](../../../experiments/value_lr_physical/freeze_calibration_ceiling.py)只读取已生成的二元评分，不调用模型或在线 API。
