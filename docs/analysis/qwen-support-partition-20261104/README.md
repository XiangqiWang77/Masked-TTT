# Qwen：全文独有正确的题，选块覆盖了什么？

针对已完成的 Qwen3-4B BABILONG **1,000 题**，这份分析把原始标注支持事实与实际选中的约 10% 原文块对齐，再按全文模型和 ICL Teacher 是否答对分组。1,000 题来自 250 个来源问题，各有四种长度；问题和四种长度并非相互独立。

| 全文 / Teacher 结果 | 题数 | 支持事实完整覆盖 | 至少一条未覆盖 | 独立 Cartridge 答对 |
|---|---:|---:|---:|---:|
| 全文对、Teacher 错 | 106 | 55 | 51 | 3 |
| 全文错、Teacher 对 | 172 | 134 | 38 | 162 |
| 两者都对 | 441 | 407 | 34 | 428 |
| 两者都错 | 281 | 191 | 90 | 9 |

最值得关注的是第一行：全文模型能答对而 Teacher 答错的 106 题中，**51 题漏掉至少一条标注支持事实**，另 **55 题已覆盖全部标注支持事实**。当前原问题格式的 Cartridge 在这 106 题中答对 3 题。针对漏选，应改进同预算下的选块；针对已覆盖却答错的题，应继续检查问题条件、读取方式和推理，不能仅凭覆盖数认定原因。

两个题型展示了不同需求：在全文对、Teacher 错的 QA1 中，21 题有 17 题漏掉标注支持事实；QA7 的 21 题则有 19 题已覆盖标注支持事实。这里的「完整覆盖」只表示标注事实的原文跨度均被选中，不代表模型已正确使用这些事实，也不保证其他未标注的上下文关联完整保留。

分组同时显示选择视图的价值：Teacher 独有正确的 172 题中，原问题格式的 Cartridge 答对 162 题。Teacher 使用通用回答格式要求，而原问题格式的 Cartridge 使用不同后缀，因此这些差异不能全部归因于 TTT 更新。

事实标注和参考答案均在保存模型输出之后才用于覆盖统计和统一的 `answer_focused_lexical_v2` 宽松词面评分。脚本逐题核对缓存的 Decision 分数与选块，并复核此前已检查的 200 题；总准确率也与已有 1,000 题报告一致。开发与留出来源问题分离，但此前已查看过部分留出来源和旧配置汇总。这是事后定位，不是新选块配置的盲测效果。
