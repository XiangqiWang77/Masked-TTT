# 按题型检查 OLMo 涨点与跨模型复现

每个模型使用相同的 1,000 道 BABILONG 题目，统一使用宽松词面评分。以下每种题型 100 道，来自 25 个来源问题的四种上下文长度；表中数字为准确率（%）。

OLMo 表使用独立配对复跑，整体 Teacher 41.00%、零更新 44.30%、TTT 44.50%；最初那轮分别为 41.20% 和 44.60%。两轮的 Teacher 都有额外格式要求。在本次复跑的 QA4 与 QA10 中，零更新相对 Teacher 分别高 14 和 10 题，TTT 相对相同格式的零更新分别再高 2 和 0 题。

GPT-OSS 的 QA10 原问题格式为 38% → 40%；改用通用格式时为 50% → 51%。格式会改变模型回答内容，这一事后对比用于设计后续固定设置，不能当作新的留出集结果。
