# Qwen：自练习提示的同 GPU 配对

| 题数 | 全文 | 选中缓存零更新 | ICL Teacher | 原提示卡带 | 改进提示卡带 | 相对原提示 |
|---:|---:|---:|---:|---:|---:|---:|
| 200 | 57.50% | 57.50% | 59.50% | 59.00% | 59.50% | +0.50 点 |

改进提示相对原提示新答对 1 题、新答错 0 题；与 Teacher 的差为 +0.00 点。两组卡带使用相同原问题格式，Teacher 附带通用回答格式要求。

10 题无标签预探针中，改进提示的已核验练习数由 0 增至 2；但在完整 200 题中，两种提示分别产生 48 和 43 个已核验练习，有 18 题变多、21 题变少。

两组顺序运行在同一已加载模型和 GPU，使用相同选块、Teacher 生成 token 和零更新答案；每组均独立 prefill、训练、物化并在回答前释放全文及选中源缓存。完整 Teacher 概率张量未逐元素比较。

这是用于选参数的 200 题开发集，包含 50 个来源问题的四种长度。结果没有超过同轮 Teacher，因此按预定规则不扩展这一候选到 800 题。统一使用宽松词面评分，参考答案仅在生成后用于评分。
