# Value 学习率与步数：同题配对

这是已完成的 200 题开发集事后分析：每种模型 50 个来源问题，各有四种上下文长度。两种候选都使用原 Decision 分数前约 10% 的块和原式全文 Student 自蒸馏。

| 模型 | 严格匹配题数 | Teacher | 选中零更新 | Value LR 0.001 | 8 步 | 0.001 相对 8 步：新对 / 新错 |
|---|---:|---:|---:|---:|---:|---:|
| qwen | 200 | 52.50% | 52.00% | 51.50% | 51.50% | 1 / 1 |
| gpt | 163 | 51.53% | 50.31% | 52.15% | 50.92% | 2 / 0 |

严格匹配要求同题的选块、Teacher token、已验证练习、初始学生前缀、零更新 token 和原学习率的第 2 步输出相同。两轮可能在不同 GPU 上运行；GPT 有 163 题满足所有条件，Qwen 为 200 题。训练和回答均未读取评测答案。Teacher 带通用回答要求，两个卡带候选使用原问题格式。开发集的配对输出来自选中 KV，但部分诊断状态当时仍在内存中；物理释放由留出实验另行验证。

在这批严格匹配的 GPT 题中，0.001 相对 8 步新答对 2 题、新答错 0 题；这支持先完成已提交的更强 Value 学习率验证。两种分别训练的结果并不能预测把高学习率与 8 步组合后的准确率。

[聚合数据](summary.json)不含原文、答案或逐题 ID；本分析没有重新调用模型或 API。
