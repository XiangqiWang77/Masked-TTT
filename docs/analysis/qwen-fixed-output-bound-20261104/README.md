# 现有 Qwen 答案的选择空间

Qwen 的 1,000 题已有同缓存零更新和训练后两份答案。为判断是否应该只调选择门控，我们计算一个理想上界：假设能事先知道答案对错，每题都在**这两份已生成的答案**中选正确的一份。这个假设使用评测结果，只用于事后分析，不能作为实际推理规则。

| 两份已有答案 | 第一份 | 第二份 | 新对 / 新错 | 理想选择上界 | 相对 Teacher |
|---|---:|---:|---:|---:|---:|
| 原格式零更新 / 原格式训练后 | 59.40% | 60.20% | 14 / 6 | 60.80% | −0.50 点 |
| 通用格式零更新 / 通用格式训练后 | 61.30% | 60.90% | 8 / 12 | 62.10% | +0.80 点 |
| Teacher / 原格式训练后 | 61.30% | 60.20% | 12 / 23 | **62.50%** | **+1.20 点** |

同一批题的 ICL Teacher 为 **61.30%**。例如第二行中，零更新答对 613 题，训练后另外修对 8 题，因此两份答案的理想并集最多答对 621 题。目标若是相对 Teacher 提高 3 点，即 **64.30%**；即使第三行事后理想选择 Teacher 或原格式卡带，也只能到 62.50%，相差 1.80 点。该行是关于已有输出的理论比较；当前方法正式回答时并不提供 Teacher 答案。

因此，提高效果的主要方向是让新的选块、训练或卡带读出产生更多正确答案，而不仅是在这两份已有答案之间调门控。该结论只针对这轮具体配置的已生成答案，不限制新的训练或选块方法。Teacher 格式的两份卡带答案为释放前的同缓存配对诊断；实际门控既没有参考答案，也没有这个理想上界的能力。
