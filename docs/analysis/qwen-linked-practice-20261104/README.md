# Qwen：有效自练习与卡带结果

对已完成的 Qwen 1,000 题做事后配对分析。选块预算约为 10%，学习目标为原有的 on-policy Teacher→Student KL；答案统一用 `answer_focused_lexical_v2` 评分。下表的“零更新”和“卡带”使用同一选中缓存和同一原问题格式；新对、新错分别是零更新错而卡带对、零更新对而卡带错。

| 原文核验通过的小题 | 题数 | 来源问题数 | 零更新 | 卡带 | 新对 / 新错 | 提升 |
|---|---:|---:|---:|---:|---:|---:|
| 0 个 | 829 | 242 | 59.59% | 60.07% | 9 / 5 | +0.48 点 |
| 至少 1 个 | 171 | 93 | 58.48% | 60.82% | 5 / 1 | +2.34 点 |
| 合计 | 1,000 | 250 | 59.40% | 60.20% | 14 / 6 | +0.80 点 |

已核验组在原问题格式下出现较大增益，留出集的 131 题是新对 4、新错 0；这支持继续测试提高有效小题比例。组别是运行结果，不是随机分配：问题类型和难度不同，250 个来源问题各出现在四个长度中，同一来源也可能落入两个分组，因此不能把这 2.34 点当作自练习的因果效果。

输出格式也会影响结论。若零更新与卡带**都使用 Teacher 的通用回答格式**，171 题的配对结果是新对 1、新错 4，整体为新对 8、新错 12。正式 Teacher 61.30%，原问题格式卡带 60.20%；两者格式不同。不能把格式或练习组别造成的差异全部归因于 SD。

1,000 题中 829 题没有通过核验的小题；日志记录了 310 次 JSON 解析失败、104 次引用不在选中块、94 次重复或照搬原问题。这些是拒绝事件数，同一题可有多次拒绝，不能相加解释为不同题数。当前候选作业先测试改变小题措辞是否真的提高通过数量，再用同 GPU、同格式的 200 题配对确认回答收益；仅在超过对照时继续留出集。
