# SD 训练问题格式对齐：200 题结果

这项开发实验保持 Decision 缓存选块、选中 Teacher、全文 Student、on-policy KL、原文档低秩基底和独立卡带；只让 Student 训练时的问题后缀包含 Teacher 的通用回答要求。最终卡带仍用原问题格式生成。每模型 200 题来自 50 个来源问题在四种长度下的扩展；评分是 `answer_focused_lexical_v2`，参考答案只用于生成后评分。

| 模型 | 全文 | 选中零更新 | ICL Teacher | 格式对齐 SD | 相对 Teacher |
|---|---:|---:|---:|---:|---:|
| Qwen3-4B | 57.50% | 57.50% | 59.50% | 58.00% | −1.50 点 |
| GPT-OSS-20B | 53.50% | 61.00% | 62.00% | 61.00% | −1.00 点 |

与原 SD 做更严格的历史配对，要求选块、Teacher token、自练习和零更新输出相同：Qwen 的 192 题新对 0、新错 0；GPT-OSS 的 167 题新对 2、新错 2。原 SD 与本实验分属不同运行，严格匹配能检查日志中可见的对照，但不意味着比较了完整的 Teacher 概率张量。

两种模型的 200 题结果都未超过各自 Teacher，按照预先设定的筛选条件，这个候选不进入 800 题扩展。该结论只针对当前格式和开发集；后续优先检查小题质量、选块与模型内更新，而非据此宣称格式调整对所有场景无用。代码在 [prompt_alignment](../../../experiments/prompt_alignment/)；没有新增 API 调用。
