# Cartridge 的回答格式对照

Teacher 的问题后缀包含通用输出要求：只给最终答案、不要解释。原始独立 Cartridge 使用原问题后缀。两者都没有看到 Teacher 的答案；但提示不完全相同，因此需要在同一个选中缓存、同一训练状态和同一生成上限下分别比较。

## 可选实现

默认 `standalone_answer_format="original"` 保持原行为。设为 `"teacher_requirements"` 后，独立 Cartridge 重新输入同一个问题以及 Teacher 的通用回答格式要求。训练仍在全文 Student 上使用原来的 Teacher KL；选块、KV 更新和缓存释放均不变。这个选项从 Teacher 输入中读取**问题后缀**，不读取或拼接 Teacher 生成的答案。

命令行可用 `--standalone-answer-format teacher_requirements`。已有学习率实验仍使用原格式，并继续分别记录两种格式，避免改变已提交实验的对照条件。
