# Masked TTT via Selective Self-Distillation

## 想解决什么

长文档包含完整证据，但当前问题可能只需要其中少数片段。全文模型能看到完整材料，却需要从大量位置中找证据；只看相关片段更集中，却可能漏掉必要条件。

我们把两者结合：**用片段构造聚焦的学习信号，让 Student 保留全文视野并学习如何读取。** 每个请求有自己的一份临时适配状态，基础模型参数不变。

## 1. 选出学习材料

把文档切成大约 256 token 的 chunk。Decision API 根据原问题给每块打相关性分数，默认选得分最高的 10%，再按原顺序排列。

预处理时可以把分数保存成 JSON。运行时按 case ID 和问题复用 JSON，无需为每个模型再次调用 API。选块确定两件事：Teacher 看哪些材料，以及 Student 的哪些文档位置允许被适配。

在输入能装进模型窗口时，未选中的材料仍在 Student 的上下文里。若超过模型原生窗口，程序会构造一个以选中内容优先的工作文档，并在结果中记录裁剪映射。

## 2. 构造聚焦 ICL Teacher

冻结模型只看选中的原文、原问题和原有任务格式。Teacher 生成一个短回答前缀，并记录每个位置的完整下一 token 概率分布。目标在训练期间固定，不接收梯度。

例如，Teacher 对两个候选值分别给出 0.7 和 0.25，Student 使用的是整份分布，而不只是第一名。这个分布包含了 Teacher 对候选答案的相对偏好和不确定性。

当前快速配置最多生成 32 个 Teacher token，并要求简洁回答。它不生成草稿，也不调用额外的 LLM Judge。Teacher 可以出错，因此最终质量需要通过同题评测衡量。

## 3. 在 KV 读取上做请求内适配

模型阅读文档时，每层把已经读过的位置表示为 Key 和 Value：

- **Key** 帮助当前 Query 判断应关注哪些位置。
- **Value** 是注意力加权后交给后续网络的内容。

Student 先用冻结模型为完整工作文档建立原始 KV。原始缓存只读，模型参数也不更新。我们额外训练两种小修正，仅在选中 chunk 的位置上生效：

1. **读取分配**：每层、每个 KV 头、每个选中 chunk 有一个注意力分数偏置，改变这块分到的注意力份额。
2. **读取内容**：每层、每个 KV 头共享一个从选中原始 Value 构造的固定低秩基，每个选中块学习自己的系数，为 Value 增加有界残差。

数学上，对选中标记为 $m_u$ 的位置，读取分数和内容为

$$
z_{t,u}=\frac{q_t^\top k_{u,0}}{\sqrt{d_h}}+m_u g_{c(u)},\qquad
\widetilde v_u=v_{u,0}+m_u\Delta v_u.
$$

当前实现中 $\Delta v_u=\operatorname{clip}((v_{u,0}U)B_{c(u)})$，残差范数不超过原 Value 范数的 15%。未选中位置的偏置和残差均为零。开头的 attention sink 位置也不修改。

这不是更新模型的 $W_Q$ 或 $W_V$。它改变的是本次请求读取已有 KV 时的计算；原文 KV 始终可以作为不适配的参照。

## 4. 用自蒸馏联合更新

Student 在全文条件下，沿 Teacher 的同一回答前缀预测下一个 token。每个答案位置计算

$$
\mathcal L_{\mathrm{SD}}
=\operatorname{mean}_{i}\mathrm{KL}\left(
p_T(\cdot\mid E,Q,y_{<i})\;\Vert\;
p_S(\cdot\mid D,Q,y_{<i})
\right).
$$

同一次反向传播同时更新读取分配和内容修正。基础模型虽不更新，但梯度仍穿过它的计算路径传到这两组临时参数。训练严格因果：预测第 $i$ 个答案 token 时，只能看到前 $i-1$ 个答案 token。

当前默认是 2 步 Adam。对于能识别答案选项的选择题，训练聚焦 Teacher 选项对应的位置，并可在 KL 仍大时继续到最多 8 步；其他回答使用 Teacher 前缀上的全部位置。

这里的 **selective SD** 指“只用选中 chunk 构造监督，并只修改这些位置的读取”。它不是一个额外的逐题 Judge。我们测试过轻量筛选候选，但没有把未经验证的筛选器加入当前全量运行。

## 5. 重新回答并丢弃状态

优化完成后固定临时状态，清除训练中使用的答案后缀。Student 重新处理原问题，并在全文工作上下文下独立生成答案。Teacher 答案不会被放入正式回答提示。

请求结束后，临时修正和优化器状态全部丢弃；同一模型可以服务下一请求。

## 为什么值得这样做

- **质量**：选块帮助 Teacher 集中产生问题相关的监督；Student 保留完整工作上下文，可以利用 Teacher 没看到的证据。
- **内部适配**：Teacher 信号改变的是后续读取文档的方式，Student 自己生成答案，因此结果可以与 Teacher 不同。
- **效率**：Teacher 只处理选中的材料，训练只使用短回答前缀与少量更新。学生仍需要读取工作文档，因此总成本还取决于全文长度和实现。

历史 Qwen BABILONG 999 题实验中，另一版带筛选的设置比 ICL Teacher 高 3.20 个百分点。当前仓库的快速设置省去了当时的额外 Judge，质量和 TTFT 正在用配对实验分别衡量；这两个配置不应混为一谈。
